## 💡 TIPS FOR BEST RESPONSE

### **✅ DO:**
- ✓ Provide clear subject line
- ✓ Include relevant order numbers
- ✓ Be specific about the issue
- ✓ Include contact information
- ✓ Attach relevant images/documents (coming soon)

### **❌ DON'T:**
- ✗ Write in ALL CAPS
- ✗ Send multiple duplicate messages
- ✗ Include sensitive payment info in message
- ✗ Be vague or unclear
- ✗ Expect immediate response outside hours
